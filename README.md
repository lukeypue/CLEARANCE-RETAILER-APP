# Clearance Retailer App

Android clearance browsing for individual stores and across Walmart, Target, Home Depot, Lowe's, Tractor Supply, and Walgreens.

The first Android test version is being developed on `codex/android-foundation`. It uses clearly labeled sample inventory to test browsing, filtering, saved items, and price history. Live store inventory is not connected yet.

No API keys or retailer account credentials belong in this repository.
